## 📖 Giới thiệu dự án

**Cuộc Đại Thanh Lọc** là một ứng dụng web đơn (Single-file Web App) được thiết kế với giao diện **5.0 Huyền bí (Mystic Dark Mode)** tối tân, mang đến trải nghiệm đọc sách, nghiên cứu tâm linh và sấm truyền cực kỳ mượt mà. 

Toàn bộ mã nguồn được tối ưu gọn gàng trong một file duy nhất (`index.html`), giúp bạn dễ dàng lưu trữ, chỉnh sửa trực tiếp trên điện thoại di động thông qua **Acode**, **Trebedit**, hoặc xuất bản miễn phí lên **GitHub Pages**.

---

## 📚 Danh mục bài viết chuyên sâu

1. **Cuộc Đại Thanh Lọc (2019 - 2034):** Phân tích sâu sắc về chu kỳ chuyển đổi vũ trụ, thanh lọc nghiệp quả và bước ngoặt nhân loại.
2. **Trạng Trình (Nguyễn Bỉnh Khiêm):** Luận giải sấm ký, tầm nhìn thiên tài và lời tiên tri xuyên thế kỷ của Tuyết Giang Phu Tử.
3. **Sư Vải Bán Khoai:** Cuộc đời ẩn dật, đạo pháp cơ hồ và những lời huấn dụ đanh thép thức tỉnh chúng sinh miền Nam bộ.
4. **Đức Huỳnh Giáo Chủ (Huỳnh Phú Sổ):** Tôn chỉ hành đạo Phật giáo Hòa Hảo, sấm giảng thi văn toàn bộ và con đường tu thân cứu thế.
5. **Phật Thầy Tây An (Đoàn Minh Huyên):** Khai sáng Bửu Sơn Kỳ Hương, phép lạ hóa độ và nền tảng tâm linh Nam Kỳ lục tỉnh.

## 🛠️ Hướng dẫn sử dụng trên Mobile (Acode & Trebedit)

Bạn có thể chỉnh sửa và chạy trực tiếp website này trên điện thoại Android/iOS của mình:

### 1. Sử dụng Acode (Android)
1. Tải ứng dụng **Acode** từ CH Play.
2. Clone hoặc tải file `index.html` từ kho lưu trữ GitHub này về điện thoại.
3. Mở Acode, chọn **Open File** và trỏ đến thư mục chứa file `index.html`.
4. Nhấn nút **Play** ở góc trên bên phải để xem trước giao diện trực tiếp trên WebView của Acode.

### 2. Sử dụng Trebedit (Android/iOS)
1. Tải ứng dụng **TrebEdit** trên kho ứng dụng.
2. Mở ứng dụng, chọn mục **Workspace** hoặc tạo file mới tên `index.html`.
3. Copy toàn bộ mã nguồn dán vào, sau đó nhấn **Run** để trải nghiệm website.

## 🚀 Triển khai lên GitHub Pages (Miễn phí)

Để đưa website này lên Internet cho mọi người cùng truy cập:

1. Tạo một Repository mới trên GitHub (Ví dụ đặt tên: `cuoc-dai-thanh-loc`).
2. Tải file `index.html` lên repository bằng cách bấm **Add file** -> **Upload files**.
3. Vào phần **Settings** của repository -> Chọn mục **Pages** ở thanh bên trái.
4. Tại mục **Build and deployment**, phần **Branch**, chọn `main` (hoặc `master`) và thư mục `/ (root)`. Nhấn **Save**.
5. Đợi 1-2 phút, GitHub sẽ cung cấp cho bạn một đường link công khai (Ví dụ: `https://username.github.io/cuoc-dai-thanh-loc/`).
